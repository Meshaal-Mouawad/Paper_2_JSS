# Organizer / Collection Guidance

## Recommended reviewer count

Use **3 independent reviewers**.

Three reviewers are preferred because:
- two reviewers allow agreement measurement;
- a third provides a stronger basis for disagreement resolution;
- majority agreement can be reported where all three provide applicable labels;
- the study is less dependent on one reviewer pair.

Two reviewers is the minimum workable design. Three is the recommended design for this submission.

## Distribution

Send one reviewer-specific ZIP to each reviewer:
- `Reviewer_1_Independent_Evaluation.zip`
- `Reviewer_2_Independent_Evaluation.zip`
- `Reviewer_3_Independent_Evaluation.zip`

Do not send the organizer key.

Reviewers complete Phase A before Phase B and work independently.

## Files to collect from each reviewer

Collect:
- completed `manual_review_form.csv`
- completed `obligation_review_form.csv`
- optional `reviewer_notes.txt`

Store them as:

- `R1_manual_review_form.csv`
- `R1_obligation_review_form.csv`
- `R2_manual_review_form.csv`
- `R2_obligation_review_form.csv`
- `R3_manual_review_form.csv`
- `R3_obligation_review_form.csv`

Preserve the original returned files before any adjudication.

## Required completeness check

Before analysis:
1. Every reviewer must have 28 Phase A rows.
2. Every reviewer must have 28 Phase B rows.
3. Phase B labels must be PASS / FAIL / NA only.
4. Case IDs must remain C01–C28.
5. Evidence notes should be present for FAIL labels and preferably for all applicable labels.
6. Review-time fields should be populated where feasible.

## Planned analysis after collection

### Obligation-guided evaluation
For each of the four obligations:
- applicable case count;
- pairwise raw agreement among all reviewer pairs;
- Fleiss' kappa across three reviewers where mathematically defined;
- case-by-case disagreement table;
- final adjudicated label;
- checker versus adjudicated TP, FP, FN, TN;
- precision and recall on this fixed 28-case evaluation set.

### Unaided baseline
Report:
- number of cases where each reviewer found at least one issue;
- overlap in discovered issues;
- post-freeze mapping of free-text issues to the four obligations;
- median and IQR review time per reviewer;
- comparison of issue coverage between unaided and guided phases.

## Adjudication

Only after all six returned CSV files are frozen:
1. Reveal disagreements.
2. Conduct adjudication using the visible dossier evidence.
3. Preserve all original reviewer labels.
4. Create an adjudication file with:
   - case ID;
   - obligation;
   - R1 label;
   - R2 label;
   - R3 label;
   - final adjudicated label;
   - evidence rationale.

The organizer key may be used only after independent review is complete when mapping blinded case IDs back to dossier filenames for manuscript reporting.

## Evidence integrity

Do not modify the 28 dossier files during review.
Do not expose checker outcomes or organizer labels before collection is complete.
Archive the exact distributed ZIPs and exact returned files.
