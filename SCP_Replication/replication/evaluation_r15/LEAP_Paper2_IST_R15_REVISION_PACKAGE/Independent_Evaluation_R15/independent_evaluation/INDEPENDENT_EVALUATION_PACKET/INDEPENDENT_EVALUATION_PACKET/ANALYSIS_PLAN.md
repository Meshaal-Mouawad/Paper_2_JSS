# Predeclared Independent-Evaluation Analysis Plan

## Units
- Unit of review: one frozen LEAP dossier.
- Cases: 28.
- Two phases: unaided manual review, then obligation-guided review.
- Preferred independent reviewers: 2.

## Primary independent-evaluation questions
1. Do independent reviewers assign the same obligation labels to the same dossier evidence?
2. Where does the executable checker disagree with independent human labels?
3. Does the obligation-guided procedure change issue coverage or review time relative to unaided review?

## Metrics
For each obligation:
- n eligible labels;
- reviewer agreement count and percentage;
- Cohen's kappa when mathematically defined;
- checker/human TP, FP, FN, TN after adjudication;
- precision and recall only for the adjudicated 28-case set, with no population interpretation.

For review effort:
- median seconds per dossier and IQR for each phase;
- within-reviewer difference between guided and unaided phases.

## Adjudication
After independent forms are frozen, reviewers discuss disagreements and create one adjudicated label per case/obligation. The adjudication file must preserve both original labels, the final label, and the evidence rationale.

## Stopping rule
All 28 cases must receive independent labels from the planned reviewers before the checker-evaluation result is incorporated into the manuscript.
